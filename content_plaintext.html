🧬 Quantum Model Card — EndoTrack QK-SVM v0.1

Following Everitt & Ji (2024), Model Cards for Quantum Technologies Reporting, arXiv:2412.13151, and the RRI framework (Stilgoe et al. 2013). This is a transparency document for a research prototype on synthetic data — not a clinical tool.

Description
A quantum-enhanced support-vector machine using a data-dependent ZZ feature map; the fidelity kernel between patient feature vectors is measured by SWAP tests on the Selene emulator, then scored by a classical SVM (Havlíček-style quantum kernel).
Training data
Synthetic, near-independent biomarker feature vectors (6 axes: genetic/proteomic/steroid/miRNA proxies). No personal or sensitive data — Nexus T&C compliant. Public aggregate anchors: BCAC summary statistics, CRUK stats, BCDB.
Input / Output
Input: normalised multi-omics feature vector ∈ ℝ⁶ (each feature in [0,1]). Output: binary triage risk score; in the certified demo, order-3-interaction labels vs order-1 controls.
PropertyValue
ArchitectureZZ-entangled angle-encoded feature map, L=3 re-uploads, SWAP-test fidelity kernel, classical SVM (kernel='precomputed', C=1)
Hardware (current)Selene emulator / Quest state-vector (≤10 q), Playpond builds (browser); H2-native mapping in progress (30% hardware-utilisation track)
Software stackguppylang 1.0.1, selene-sim, scikit-learn 1.9, numpy/scipy
Provenance & reproducibilityEvery number tied to a named run + seed; probability claims carry 4√(0.5/shots) envelope; results committed as JSON in arunnadarasa/nhsquantinuum
Fairness / biasSynthetic data only — no real patient bias can be certified; sex/gender and ethnicity axes deliberately excluded from claims until real (public-aggregate) cohorts
Known limitationsSmall-cohort variance (±0.24 AUC at n=28); entanglement-ablation gap directional but ~1σ at n=28 (n=56 seal in progress); emulator results ≠ on-device results
GovernanceNICE 2026 draft guidance on biomarker tests cited; EndoTrack is an early-use research prototype, not a regulatory submission
